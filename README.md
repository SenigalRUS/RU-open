# RU-open

Список доменов и сетей, которые корпоративный VPN должен отправлять напрямую через RU VPS, минуя FIN VPS.

## Файлы

- `ru-domains.txt` - домены для маршрутизации через RU.
- `ru-networks.txt` - отдельные IPv4-адреса и CIDR-сети для маршрутизации через RU.

## Формат

Одна запись на строку. Пустые строки и строки, начинающиеся с `#`, игнорируются.

Пример:

```text
yandex.ru
avito.ru
sber.ru
```

Для сетей:

```text
203.0.113.15/32
198.51.100.0/24
```

## Как это используется

RU VPS периодически загружает эти файлы из GitHub. Домены резолвятся в актуальные IPv4-адреса и добавляются в набор маршрутизации RU. Все остальные ресурсы продолжают идти через FIN VPS.

Если GitHub временно недоступен или новый файл не проходит проверку, сервер сохраняет предыдущий рабочий список.
